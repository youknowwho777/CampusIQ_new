# CampusIQ — Smart Academic Management System

CampusIQ is a full-stack academic management web application built with **React**, **Vite**, **Tailwind CSS**, **Node.js**, **Express**, **Prisma ORM**, and **Cloud PostgreSQL (Neon)**.

Because the database is hosted in the cloud on **Neon PostgreSQL (AWS us-east-2)**, this project **can be run on any laptop or computer with internet access** without needing a local PostgreSQL installation!

## 🚀 How to Run on Any Laptop

### Step 1: Start Backend (Terminal 1)
```powershell
cd backend
npm install
npm run dev
```
*(Backend runs on `http://localhost:5000`)*

### Step 2: Start Frontend (Terminal 2)
```powershell
cd frontend
npm install
npm run dev
```
*(Frontend runs on `http://localhost:5173`)*

Open **`http://localhost:5173`** in your browser!
